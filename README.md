# Sistema de Administración de Citas para Consultorio Clínico

Programa desarrollado en Java que simula un sistema de administración de citas
para un consultorio clínico. Permite dar de alta doctores y pacientes, crear
citas relacionadas con un doctor y un paciente, y controla el acceso al sistema
mediante administradores autenticados con identificador y contraseña.

## Instalación y configuración

Requisitos: JDK 11, Git e IntelliJ IDEA (opcional).

Clonar el repositorio:

git clone git@github.com:AL07075185/sistema-citas-clinica.git
cd sistema-citas-clinica

Las instrucciones de compilación y empaquetado se documentarán en la entrega final.

## Uso del programa

El sistema opera mediante menús de consola. Tras autenticarse con las
credenciales de administrador, es posible gestionar doctores, pacientes y
citas. La información se almacena en archivos de texto plano.
